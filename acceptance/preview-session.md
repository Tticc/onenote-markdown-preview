# 预览集中验收步骤

## 0. 受控准备

先同步笔记并正常退出 OneNote。脚本检测到仍有 ONENOTE 进程时拒绝注册；不强制结束。当前配置与入口默认禁用。

注册仅供手动加载：项目根目录运行 `tools\Register-Preview.ps1`。它校验构建完整性、拒绝已有注册，仅创建本预览 HKCU CLSID/AppID/ProgID/OneNote Addins 项，LoadBehavior=0，不启动 OneNote。

卸载回退随时可运行 `tools\Register-Preview.ps1 -Remove`；只删除本预览四个注册根，不删除笔记或其他插件。实际卸载需正常断开或重启宿主，不删除加载中的 DLL。

## 1. 同一批人工操作

1. 正常打开 OneNote，文件 → 选项 → 加载项 → COM 加载项 → 转到，勾选 **OneNote Markdown Preview (manual load)**。
2. 确认出现 **Markdown 预览** 选项卡。先不启用，正文按 Ctrl+Shift+D 不应被本插件接管。
3. 点击“启用”；返回测试页纯正文，选择 `acceptance/samples.md` 的综合 A，按 Ctrl+Shift+D 并松开。记录功能区最近状态。若提示剪贴板未支持，不要反复触发，记录当时复制来源即可。
4. 初次真实解析器集成仅做一次原生 Ctrl+Z，确认 A 源码与段落恢复。之后不重复已有固定样例。
5. 用样例 B/C 验证整段拒绝/无需转换；再检查标题、搜索、多窗口等拒绝路径。焦点不符不强行恢复；按钮路径可能提示用正文快捷键。
6. 禁用，记事本和正文各按一次快捷键，确认本插件未拦截。重新启用时在正文连续/长按仅产生一个操作，不排队。
7. 需要验证 500 ms 时，禁用后将 `%LOCALAPPDATA%\OneNoteMarkdownPreview\restore-delay-ms.txt` 写为 `500`，再启用；测试一个普通样例，不重复全部矩阵。
8. 结束后禁用并在 COM 加载项中取消勾选，正常退出 OneNote。由自动检查确认残留/注册状态；最后移除预览注册。不要自行启用 LoadBehavior=3。

## 2. 统一反馈

按 samples.md 的表格一次反馈。某一步出现卡住/清理提示或意外改动时停止整批，不继续启动多个实例；先回退注册，保留笔记，不删除缓存。
