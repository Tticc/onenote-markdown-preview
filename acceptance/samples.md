# 综合样例（人工放入一次性页面，不由构建自动写入）

## A. 在纯正文容器内选择整个样例

```text
# 一级标题
## 二级标题
### 三级标题

前文 **粗体**、*斜体*、~~删除线~~、`code` 后文，中文😀。

- 无序第一项
- 无序第二项

1. 有序第一项
2. 有序第二项

- [ ] 未完成
- [x] 已完成

> 引用文字
```

预期：支持项正确，行内代码有浅灰底色，任务项为符号。只在初次真实解析集成验收时做一次原生撤销，检查完整源码/结构恢复。

## B. 整段拒绝

```text
**支持部分** 和 [未支持链接](https://example.com)
```

```text
**已闭合** 与 **未闭合
```

````text
普通文字
```
    code
```
````

这些均不得部分改写；未知结构、跨容器/跨单元格、标题/搜索、图片混选、多窗口同样拒绝。

## C. 普通文本

```text
这是普通文字，没有需要转换的 Markdown。
```

预期无需操作，不新增粘贴/撤销单元。
