## Context

离线实现现状与具体保守子集/参数见 implementation-contract.md，预览限制见项目根目录 preview-review.md。这些实现不等同宿主验收通过。

当前项目没有应用代码。目标环境实测为 OneNote 16.0.19127.20860、Office x64，Click-to-Run 安装标识为 HomeStudent2019Retail（不据此推断授权）。用户接受最小启动开销和非零宿主风险，优先要求失败前不修改正文、限制写入范围、一次原生撤销。

用户已手工验证两个场景：段内粗体替换、多段标题/列表替换，均可一次 Ctrl+Z 恢复且选区外内容不变。这是用户报告的手工证据，不是插件集成测试，也未记录复制源格式、粘贴选项和段落终止符的全部细节。

## Goals / Non-Goals

**Goals:**
- OneNote 内提供极简入口，支持严格范围内的选区格式化。
- 通过外部进程隔离转换工作，用户控制其常驻生命周期。
- 把安全要求转为可验证的拒绝规则和发布关卡。

**Non-Goals:**
- 实时预览、自动监听页面、全页转换、联网服务、语法高亮。
- 多窗口转换、混合对象选区、跨文本容器或跨表格单元格转换。
- 原生标题样式、原生可交互待办标签、直接改写 .one 文件。
- 绝对无崩溃保证、任意剪贴板格式的通用无损序列化、普通辅助进程的权限沙箱承诺。

## Decisions

### 0. 当前生效的架构修订：合并到 COM 代理进程

后续真实加载证实，当前 DllSurrogate 注册使插件运行于独立 dllhost.exe。用户明确选择把转换模块合并到该代理，接受极端故障使入口失效、可能需要手动重新连接或重启 OneNote。此决定取代下文历史方案中独立转换进程、命名管道 IPC 及按需启动/关闭 worker 的安排；其余选区、剪贴板与验证关卡保持不变。

当前结构：OneNote.exe 负责编辑与持久化，通过 COM 调用 dllhost.exe；dllhost 内包含入口、状态管理、选区复核、受限转换及粘贴协调。转换按用户触发在后台任务执行，不在 OnConnection 或同步 Ribbon 回调中解析、等待转换或读取任意外部剪贴板数据源。不新增专用转换 EXE 或产品命名管道协议；Office COM 边界仍需严谨验证。

Enabled 是功能状态，不承诺禁用即关闭 Windows 管理的 dllhost。禁用后释放快捷键、不转换、不扫描，代理可因 COM 引用而暂留；**禁用按钮不得结束代理进程**。用户手动断开加载项或宿主关闭（OnDisconnection）时，插件 SHALL 在有限优雅等待（仅当操作进行中，最多 5 秒，以保全在途剪贴板恢复）后结束**自身**代理进程（`GC.Collect()` 后 `Environment.Exit(0)`）。依据：本项目两次会话共四次加载/断开/关闭验证通过，且 OneMore 在同架构下自 2016 年持续使用相同做法——存活的代理会阻塞宿主关闭。仍严禁按进程名结束 dllhost、触碰 ONENOTE.EXE 或其他 dllhost、自动重启代理。用户手动断开加载项与故障恢复仍需显式动作。

普通解析异常在操作边界捕获，失败前不提交；超时后将本次结果永久作废，不把超时等同解析线程已停止，不使用 Thread.Abort。失控任务尚未结束时不允许再启用并叠加任务。严重资源耗尽/代理崩溃不能保证执行清理、落盘停用标记或恢复剪贴板；采用持久化操作中标记，下一次初始化发现未完成操作则故障停用，等待手动恢复。该标记不包含正文，也不是文档事务日志。不得配置额外 watchdog 自动重启代理。具体恢复机制与异常宿主退出仍须首阶段验证。

以下第 1、2 节为被替代的原方案背景；凡涉及额外 worker/IPC 的表述以本节为准。

### 1. 原方案：薄 COM Add-in + 常驻 C# 辅助进程（已被第 0 节取代）

插件负责宿主入口、选区证据、快捷键、提交协调与状态。辅助进程负责 Markdown 解析和受限 HTML 生成校验。用户选择常驻而非按次启动，避免重复冷启动；没有独立托盘操作要求。

在启动关键路径之外异步启动辅助进程，不在加载回调等待它就绪，不在启动时读取笔记。具体 CLR/.NET 版本、COM 激活和安装方式在首阶段确定，不能直接套用 Word/Excel VSTO 模板。普通转换故障被隔离，但插件入口、COM 调用和宿主粘贴风险仍在。

使用具有请求标识、长度上限、协议版本及超时的本机 IPC；命名管道是优先候选，访问限定当前用户并绑定宿主会话。辅助进程不得操作 OneNote 文档或发送输入。宿主核验响应身份、大小与封装，不无条件信任返回内容。默认不落盘正文、不联网。

### 2. 原生命周期方案（worker 部分已被第 0 节取代）

状态为 Disabled、Starting、Ready、Busy、Faulted。Enabled 配置跨重启保存；手动停用与工作进程故障/超时均进入需手动启用的状态，并保存停用结果。默认初次安装保持 Disabled，需用户首次启用（部署默认值，待发布前确认）。正常宿主退出不清除用户原先的启用偏好。

Ready 接受一个操作，Busy 拒绝重复触发且不排队。用户停用时取消尚未提交的工作；如果粘贴已提交，不追加撤销，只允许必要清理按已验证策略结束。辅助进程随宿主进程退出，宿主异常结束时不得长期遗留孤儿；实现方式需验证。手动结束辅助进程视为停用，不自动复活。

### 3. 选区证据优先，无法确认则拒绝

通过 Application.Windows 检查窗口数量、窗口句柄与 CurrentPageId。首版拒绝多主窗口和快速笔记等未验证视图，避免把普通对话框误判为主窗口。调查 GetPageContent 选区标记及 UI Automation，验证是否能定位正文文本容器、范围边界、内容类型与完整段落。

仅比较文本或其哈希不足以证明相同选区；相同文本可存在于不同位置。初始和最终证据必须包括位置/容器等足够信息。只在触发时读取必要信息，不持续扫描笔记；若接口只能导出页面，应测量大型页面成本并制定限制。已存在的富文本、超链接、标签、图片等不能只因有纯文本表示就被判为纯文本选区。

鼠标、键盘不被全局锁定。编辑状态变化或证据不完整时取消，不主动导航或找回旧选区。功能区点击本身会转移焦点，必须验证其与正文选区的关系，不能把正常按钮触发等同用户变更，也不能盲目抢回焦点。

### 4. 一次原生粘贴作为唯一正文修改动作

不先删除、不剪切、不重写 Outline、不自动重试、不自动 Ctrl+Z。流程为检查环境 → 保存剪贴板 → 获取选区 → 转换及校验 → 最终复核 → 发布 HTML → 单次粘贴 → 恢复剪贴板。

提交前失败不发送修改文档的命令。提交后结果不明，停止追加编辑并显示结果不确定；不能宣称文档未变。焦点复核与执行之间仍有不可完全消除的竞争窗口，属于已披露的残余风险。快捷键注入成功不等于粘贴完成。

### 5. 剪贴板保存与恢复是发布关卡

保存独立快照，不仅持有 IDataObject 引用。枚举格式及存储介质，按经过测试的格式集合保存；遇到不支持格式、外部延迟渲染故障、大小超限或读取失败，保持原剪贴板并跳过。不得只保存文字而丢弃其他已存在格式。具体支持格式和资源限额由验证矩阵确定。

用户随后批准“常用用户内容保留”范围：上段“不丢弃其他格式”限定为承诺支持的用户内容表示，不要求保留全部应用私有粘贴能力。文本、HTML/RTF、图片分别独立复制验证；DataObject/Ole Private Data 等属于传输机制候选，不能直接按原始字节复制，只有验证可安全重建/省略后才允许。EnterpriseDataProtectionId、历史/云上传限制等可能改变保护或隐私语义的标记单独处理，不因不是可见内容就删掉。未知私有格式、文件/虚拟文件以及未批准的图形介质默认拒绝。格式分类表必须区分目标支持和实测支持，不能把支持表中列出格式等同已实现。

记录剪贴板序列与本操作所有权信息；发布、失败清理及恢复前复核，不覆盖第三方新复制内容。检查与写入应在适当的剪贴板锁定区间内进行，避免仅靠锁外序列比较造成竞争；不得持锁等待 OneNote 粘贴。

CF_HTML 使用 UTF-8 字节偏移和正确片段边界。纯文本后备格式及 OneNote 粘贴偏好必须纳入测试，不能把意外纯文本粘贴报告为格式化成功。

用户明确同意经验延迟策略：单次粘贴输入提交后默认异步等待 200 毫秒，可配置为 500 毫秒，再尝试恢复。等待期间不得占有剪贴板锁或阻塞同步功能区回调。检查本次载荷所有者与发布后的序列，在恢复锁内二次核验；任一不符则保留当前内容，不恢复旧快照。Windows 格式合成可能造成序列变化并导致保守跳过，不能误报已恢复。配置只接受 200/500，非法值回退 200 并提供配置诊断。

此修订取代必须取得自动粘贴完成证明的要求；不再用整页导出轮询或 OLE GetData 跟踪作为必需恢复条件。固定延迟及 SendInput 返回均不证明成功：繁忙系统中可能提前恢复、粘贴错误内容或失败，用户已接受该兼容性风险。状态只能报告已提交与恢复/跳过结果，不称已验证格式化成功。单次提交后不自动重试/撤销；恢复失败保留可用快照并反馈，禁止无限重试。快照支持范围不变，不支持的原格式仍须跳过。

### 6. 严格 Markdown 子集与简单输出

优先成熟 AST 解析器（Markdig 候选）加子集检查和白名单渲染，避免正则串联替换。支持 #～###、**粗体**、*斜体*、~~删除线~~、反引号行内代码、基础围栏代码块、- 无序列表、数字有序列表、- [ ] / - [x] 任务项、> 引用及普通文字。

标题为视觉层级；任务项为 ☐/☑；代码为保留空白的等宽文字；引用为简单缩进。不依赖原生标签或复杂 CSS。输入中的 HTML 不直通执行，资源不加载；具体未支持语法检测必须以语法上下文为依据，代码/转义文本中的符号不误报。发现未支持结构或确定不完整的受限语法时整段拒绝并给出类别。

行内代码视觉要求已由用户明确为等宽字体加浅灰底色。内联 span 使用 font-family:Consolas;background-color:#eeeeee，当前版本实际粘贴保留且用户接受现有效果；不额外要求边框或 padding。底色只覆盖代码，不使用图片、整段高亮或额外原生编辑命令绕过一次粘贴约束。此验证不等于所有版本兼容；围栏代码块底色未由此决定。

严格子集的嵌套、转义、未闭合语法、围栏语言标记等细节须先形成语法样例表，再锁定实现；默认解析器“解析成功”不是合格判据。校验 AST、输出标签属性、内容保真、编码与资源限额。没有可转换语法时不粘贴，避免无意义撤销记录。

### 7. 局部快捷键与轻量反馈

Ctrl+Shift+D 只在已启用且符合条件的 OneNote 编辑环境接管，禁用时释放。不能把全局 RegisterHotKey 后忽略其他应用事件称为穿透。确切接入机制、冲突处理和修饰键释放行为须验证。

功能区显示最近结果/跳过类别，不自动弹窗或抢焦点。日志只记录类别、阶段、耗时等元数据，不记录正文、HTML、剪贴板内容；避免异常字符串泄露这些数据。

## Risks / Trade-offs

- [COM 插件加载及宿主故障耦合] → 最小入口、异步启动、异常边界和可卸载安装；不能保证绝对无风险。
- [选区接口粒度不足] → 先测重复文本、段落边界和混合对象；不足则拒绝场景并停止扩大范围。
- [经验延迟可能提前恢复] → 用户已接受残余风险；默认 200 毫秒，可选 500 毫秒，保留所有权/序列保护，按实际场景验证，不宣称可靠完成通知。
- [外部应用的剪贴板对象阻塞] → 保存路径需要限时和故障隔离评估，避免在 OneNote UI 线程等待不可控数据源。
- [严格剪贴板规则导致频繁跳过] → 测试浏览器、Office 和文本来源并报告真实可用率；不悄悄丢弃格式。
- [原生粘贴偏好/Office 更新影响效果和撤销] → 记录环境与设置，按实际载荷回归，范围之外不宣称兼容。
- [合并转换任务影响代理入口] → 异步执行、有界输入、超时后丢弃结果、未完成操作标记；用户接受极端故障需重启，无法保证严重故障时清理成功。
- [最后复核之后发生焦点变化] → 最小提交窗口、可检测变化取消、绝不重试；保留残余风险说明。

## Migration Plan

用户已批准 gate-review.md：前置证据足以允许离线第 2～5 阶段；以下完整关卡约束作用于安装、宿主验收与发布，不再阻止离线构建。不得自动安装/启动加载或写真实笔记。

1. 在未来实施阶段，仅在一次性测试页执行最小技术验证；记录测试矩阵和证据。
2. 所有阻塞关卡通过后，锁定运行时、COM 代理/后台任务边界、安装及资源限额，再实现完整功能。
3. 发布 x64 安装/卸载说明及手动停用恢复步骤，验证干净环境注册和宿主正常启动。
4. 回退为禁用 COM 加载项、退出辅助进程并卸载本产品注册/文件；不删除其他插件配置或任何笔记。配置保留/清理规则在安装设计中明确。

## Open Questions

- 精确选区与完整段落证据能否在目标版本获得？按钮触发与快捷键触发是否有差异？
- 200/500 毫秒策略在目标场景的兼容性与竞争恢复测试如何？失败时快照如何保留且不泄露？
- 支持哪些剪贴板格式与介质，大小/时间/AST 深度阈值是多少？
- 实际快捷键机制、冲突反馈、COM 宿主运行时和安装权限是什么？合并后的超时/异常进程恢复机制是否符合故障停用要求？
- 子集语法边界样例、首次安装默认禁用、支持视图以及运行性能预算需在首阶段收敛。
