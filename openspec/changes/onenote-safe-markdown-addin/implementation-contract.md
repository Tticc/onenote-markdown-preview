# 离线预览实现契约

## 固定技术基线

- C#（本机 Framework csc 支持的语法），Windows x64，当前 .NET Framework 4.8 环境。
- 官方 Extensibility 7.0.3300.0、Office/OneNote 15.0 PIA；生产接口不手写 COM 契约。
- Markdig 0.37.0 net462；System.Memory 4.5.5、System.Buffers 4.5.1、System.Numerics.Vectors 4.5.0、Unsafe 4.5.3。固定版本可重建缓存，分发前仍需许可证整理与完整性清单。
- 合并 surrogate + STA 调度/后台解析；不新增产品 IPC 或转换进程。无运行时联网。

## 预览语法样例边界

| 输入 | 结果 |
| --- | --- |
| `**文字**` / `*文字*` / `~~文字~~` | 粗体/斜体/删除线 |
| 反引号包围 code | 等宽 + #eeeeee，符号作为文字而非再解析 |
| `#`～`###` 后空格标题 | 完整段落才转换 |
| `- item`、`1. item` | 基础列表，禁止嵌套，数字起点暂限 1 |
| `- [ ]` / `- [x]` | 文字符号 ☐ / ☑ |
| `> quote` | 基础引用 |
| 链接/图片/HTML/表格/扩展节点 | 整次拒绝，不只转换支持部分 |
| 未闭合星号/反引号/删除线 | 保守拒绝；转义样例单独验证 |
| 围栏和缩进代码块 | 因原空白保真未证明而拒绝 |
| 纯文字 | 无需转换，不发布剪贴板 |

上述是保守预览边界，不声称完整 CommonMark。输出经 XML 结构白名单验证，实体转义，不加载资源。UTF-8 CF_HTML 字节偏移，终止 NUL 不计入 EndHTML。

选区判定只对**被选中的 run**做严格纯文本解析；同一段落内、选区之外的 run（含此前转换产生的加粗/斜体/删除线）MUST NOT 成为拒绝理由，且必须原样保留。`wholeParagraphs` 仅在选区外的 run 含可见内容时为假。

## 资源与状态

输入 32768 字符，页面导出后检查 1,000,000 字符（不是宿主导出内存硬限制），AST 渲染节点 4096/深度 16，输出 256 KiB。原剪贴板单格式 4 MiB、总 8 MiB、128 格式。外部 OLE GetData 和 COM 调用可能阻塞 STA；合并模式下不能安全硬取消，这是发布前必须审查的限制，不宣称异步 Task timeout 解决它。

解析等待 2 秒；超时永久作废 ticket，停用，任务结束前不接受新任务。首次禁用。200/500 ms 恢复不证明成功；恢复只在锁内所有权/序列匹配时。故障后的未完成标记触发人工恢复。

跳过/失败反馈通过不抢焦点的非激活弹窗（`Toast`：`WS_EX_NOACTIVATE|WS_EX_TOOLWINDOW`、`ShowWithoutActivation`、屏幕右下、6 秒自动消失）给出原因；系统托盘气泡经实测在本环境被系统通知设置抑制，故不作为唯一通道。弹窗文本仅含原因与剪贴板格式名等元数据，绝不含正文/HTML/剪贴板字节；随进程退出或断开清理（关闭经 STA 派发），离线夹具与关闭期间不弹。剪贴板策略：`Chromium internal source RFH token`、`Chromium internal source URL` 等已分类应用内元数据格式可跳过（不保存不恢复）；其余未知格式仍默认拒绝，逐类追加并记录依据。
