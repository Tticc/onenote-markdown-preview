## Why

OneNote Windows 桌面版缺少轻量的选区 Markdown 格式化能力。需要一个集成在 OneNote 内的极简插件，在明确的选区范围和可验证的安全边界内完成格式化，并支持一次原生撤销。

## What Changes

- 新增通过 DllSurrogate 承载的 COM Add-in；插件协调与 Markdown 转换合并在同一个 dllhost.exe 中，不再新增转换进程。用户通过功能区或 Ctrl+Shift+D 触发，不自动转换页面。
- 只支持单个 OneNote 主窗口、单一正文文本容器内的连续纯文本选区；块级格式要求完整段落。
- 支持三级标题、粗体、斜体、删除线、行内代码、基础围栏代码块、基础列表、任务列表和引用；使用简单显示效果，不要求原生标题或待办标签语义。
- 使用临时 HTML 剪贴板载荷，通过一次原生粘贴替换选区；保存原剪贴板，无法可靠保存时跳过，不覆盖第三方后来复制的内容。
- 剪贴板保留范围按用户确认收敛为经验证的常用文字、HTML/RTF、图片内容，不保证全部应用私有粘贴能力；辅助元数据逐类验证，未知格式或未验证的保护语义仍拒绝处理。
- 按用户确认的工程取舍，默认等待 200 毫秒后尝试恢复原剪贴板，可配置为 500 毫秒；保留所有权/序列保护，接受繁忙场景下提前恢复的残余风险，不宣称延迟证明粘贴成功。
- 保存启用状态；手动停用、可检测的转换故障或超时后不自动恢复转换。代理进程崩溃/卡死可能使入口不可用，需手动重新连接或重启 OneNote。多窗口、选区变化、不支持语法等情况拒绝或取消操作。
- 提供不抢焦点的操作结果；日志不包含笔记正文。
- 将选区识别、自动粘贴与一次撤销、剪贴板恢复、快捷键作用范围列为首阶段技术关卡；未通过则暂停后续实现并重新讨论。

## Capabilities

### New Capabilities
- `addin-lifecycle`: 插件入口、启停持久化、辅助进程生命周期、快捷键和状态反馈。
- `safe-selection-formatting`: 受支持选区、编辑环境复核、剪贴板保存恢复、单次替换与撤销验证。
- `markdown-subset`: 严格 Markdown 子集、简单富文本渲染、全选区拒绝和输出校验。

### Modified Capabilities

无；当前没有主规格。

## Impact

- 新增 Windows 专用 C# COM 插件、同进程转换模块及安装/卸载配置；具体运行时、COM 注册方式和解析库版本在技术验证后锁定。
- 依赖 OneNote 桌面 COM 接口、Windows 剪贴板与输入接口；UI Automation 仅作为待验证的选区辅助方案。
- 首个验证环境为 OneNote 16.0.19127.20860、Office x64；不据此声称兼容所有 Office 版本。
- 接受最小可测启动开销和非零宿主风险；用户接受极端转换故障导致插件不可用、可能需要重启 OneNote。dllhost 进程隔离不等于权限沙箱，也不能保证宿主不会因同步等待而卡住。
- 本变更先完成证据驱动的可行性验证，再开展完整实现；不直接修改笔记文件或重写整个页面/Outline 来绕过选区限制。
